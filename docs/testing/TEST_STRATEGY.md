# Test strategy — proposed
Tests not executed for documentation-only changes. Backend: gofmt, go vet ./..., go test ./..., isolated PostgreSQL integration tests. Web: lockfile install, lint, typecheck/build, auth/error/loading tests. Mobile: flutter analyze/test and target build once source exists. Security: negative role/tenant CRUD and relation tests, registration, token expiry, missing production secrets, input and file quota validation. Infrastructure: health, graceful shutdown, resource limits, backup consistency and restore, synthetic peak attendance and storage growth benchmarks, rollback. No production credentials or data. Report commands, failures and skipped tests explicitly. Future release requires owner-approved gates.

# API contract — draft baseline
Go REST API is authority. Current scaffold routes: /health, /api/auth/register, /api/auth/login, /api/auth/me, /api/companies, /api/roles, /api/employees, /api/departments, /api/locations; CRUD where defined. See router and DTO source for actual methods/shape; not a stable production contract. Current auth/tenant registration behavior is unsafe for real data; see SECURITY.md. Future contracts specify request/response schemas, status codes, authorization, tenant context, pagination limits, error model, idempotency and versioning. Agree contract changes and regression tests before web/mobile integration. Never infer authorization from frontend routing or tenant slug. Use synthetic fixtures.
